self-hosted cloud

cirrocumulus

A secure mini cloud you run yourself. Every workload gets its own Firecracker microVM, locked down with jailer, managed from the terminal.

  • cirro run nginx:alpine turns an OCI image into a jailed microVM, built without root
  • cirro top is a live dashboard of every VM's CPU, memory, disk and network
  • Idle VMs park to disk and free their RAM, then wake in 54 ms p99 (measured in the README)
  • An HTTP(S) edge routes hostnames to Apps, waking them on request
